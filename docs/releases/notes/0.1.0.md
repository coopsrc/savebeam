Savebeam 首个公开版本，一个本地优先的桌面媒体下载器。

| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| macOS 12+，Apple Silicon（M 系列） | [Savebeam_0.1.0_aarch64.dmg](https://github.com/coopsrc/savebeam/releases/download/v0.1.0/Savebeam_0.1.0_aarch64.dmg)     |

## 功能

- 单视频、系列/播放列表及 Bilibili 多 P 选择下载；支持分辨率、FPS、容器、编码与音频策略和单项覆盖。
- 独立的元数据读取与下载并发管理、任务恢复、合集分组、下载历史及文件缺失标记。
- 系列订阅检查、来源变化检查和保留历史版本的重新下载。
- 可多选的字幕语言、高级下载选项、任务独立代理、全局默认配置和连接测试。
- 本地封面/元数据缓存、自定义组件路径、中英文界面和亮暗主题。

## 安装和已知限制

- **此版本尚无正式系统发行签名**：macOS 使用 ad-hoc 签名，未经过 Apple 公证；Windows 安装包尚无 Authenticode 签名，系统可能提示未知开发者或阻止启动。请仅从本仓库下载并核对 `SHA256SUMS`。macOS 用户可在尝试启动后按系统“隐私与安全性”提示处理；不需要关闭系统安全功能。
- yt-dlp、FFmpeg/ffprobe 和 Deno **未内置**。首次运行请到“设置 → 运行组件”按平台安装或指定已有可执行文件；macOS 可使用 Homebrew。应用管理组件的正式签名清单尚未发布，当前请使用系统安装或自定义路径。
- 解析和下载取决于站点、网络及用户授权；代理不能替代 Cookie 或绕过站点权限。部分网络下 Bilibili 可能返回 HTTP 412、YouTube 可能超时，不能保证所有链接均可下载。
- 本次提供手动下载，**不发布应用内自动更新元数据 `latest.json`**。系统签名/公证、完整安装升级及辅助技术人工验收仍在进行。
- 安装包随附 Apache-2.0 的应用许可和第三方声明；尚有一项 npm 包原始作者许可文本的来源复核，见 [依赖复核记录](https://github.com/coopsrc/savebeam/blob/v0.1.0/docs/verification/dependency-audit-2026-11.md)。第三方可执行组件的再分发审核另行跟踪。

应用默认在本机处理任务和媒体，不默认上传 Cookie 或下载内容。卸载应用时，下载文件和本地数据不会作为应用 bundle 一并移除。

## 完整性与反馈

`SHA256SUMS` 列出下载文件的 SHA-256；`build-info.json` 记录版本、Tag、源码提交和系统签名状态。`.sig` 是独立的更新包签名，不表示 Apple/Microsoft 系统签名通过。

反馈问题请使用 [GitHub Issues](https://github.com/coopsrc/savebeam/issues)，并注明系统、版本及复现步骤；请勿上传 Cookie、密码或含敏感信息的原始日志。
