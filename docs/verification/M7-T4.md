# M7-T4 验证记录：错误脱敏与诊断导出

## 已实现

- `AppError::with_diagnostic` 统一过滤敏感 header、疑似凭证 query 参数和用户主目录路径。
- yt-dlp 原始 stdout/stderr 不写入持久日志或导出文件；错误分类继续仅返回稳定错误码和用户提示。
- 设置页导出前明确确认，再由系统保存对话框选择本地 JSON 文件位置。
- 导出报告只含 Savebeam 版本、OS、CPU 架构、生成时间及任务状态计数，不含 URL、标题、Cookie、原始进程输出和文件路径；应用不会自动上传。
- 后端校验导出目标必须是绝对路径、`.json` 扩展名且父目录已存在。

- Vite 仍提示主 JS chunk 超过 500 kB；不影响构建通过。
