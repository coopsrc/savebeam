# M7-T7 验证记录：依赖、许可证与组件来源审计

- 审计日期：2026-10-21
- 执行平台：macOS Apple Silicon
- 范围：当前 `pnpm-lock.yaml` 生产依赖、macOS arm64 Cargo 依赖元数据、完整 `Cargo.lock` 的 OSV 批量查询，以及本地组件候选清单来源记录。

## 前端依赖

- `pnpm audit --registry=https://registry.npmjs.org --json`：241 个依赖，0 条 advisories。项目配置的 npm 镜像不支持 audit bulk API；只对本次命令指定官方 npm registry，没有更改全局或项目 registry 配置。
- `pnpm dlx license-checker --production --json`：当前生产依赖均为 MIT 或 Apache-2.0/MIT 双许可，包括 React、Mantine、Tabler、Tauri JS API/plugins、React Router 和 Zustand。
- 应用自身 `package.json` 标为 `private` / `UNLICENSED`；仓库没有根级 LICENSE、NOTICE 或 COPYING。发行源码/二进制前必须由项目所有者选择 Savebeam 自身许可证并准备所需 notices。

## Rust 依赖与 advisories

- `cargo metadata --filter-platform aarch64-apple-darwin`：322 个第三方包均有许可证字段，没有缺失 license metadata。所见许可证以 MIT、Apache-2.0、BSD、ISC、Unicode、Unlicense、Zlib 等为主；另有 5 个 MPL-2.0 包（`cssparser`、`cssparser-macros`、`dtoa-short`、`option-ext`、`selectors`）及 1 个 CDLA-Permissive-2.0 包（`webpki-roots`）。目前没有生成打包用的完整 notices 文件，且这项元数据只覆盖 macOS arm64 目标依赖图。
- RustSec 的 `cargo-audit` / `cargo-deny` 未预装；尝试用临时 Cargo home 安装扫描器时遇到 Cargo registry/cache 锁等待，未安装或改变全局工具配置。改用 [OSV 官方 `querybatch` API](https://google.github.io/osv.dev/post-v1-querybatch/) 对 `Cargo.lock` 中 526 个 crates.io 包版本直接查询。

## 上游组件来源与再分发

- yt-dlp、Deno 候选指向各自官方 GitHub Releases；真实下载包、平台兼容性和 notices 尚未逐项 smoke test。
- Windows/Linux FFmpeg 候选来自 BtbN 第三方构建；`latest` 是浮动资产 URL，精确构建配置、许可证 notices 和不可变哈希仍待复核，不能签入正式清单。
- macOS FFmpeg/ffprobe 按既定决定不由应用托管下载，仅检测 Homebrew/system 或用户指定路径。
- 候选来源与清单状态维护于 [`docs/releases/component-catalog.md`](../releases/component-catalog.md)。没有签名清单 Release，也没有进行第三方二进制再分发。
