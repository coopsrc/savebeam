# 下载目录输入与文件夹选择验证

日期：2026-10-21。

设置页“默认下载目录”保留可编辑文本输入，末尾增加文件夹图标按钮。按钮具有“选择下载文件夹”无障碍名称与“选择文件夹”悬停提示，支持键盘操作。

使用现有 Tauri dialog 插件：`directory: true`、`multiple: false`、`fileAccessMode: scoped`。当前路径非空时作为 `defaultPath`，留空时使用原生对话框默认位置，不额外读取文件或扩大权限。现有 `dialog:allow-open` 权限已满足需求。

选择成功仅更新草稿路径，仍可继续手动编辑，不自动保存。取消保留原值，选择器打开失败时显示提示并恢复手动输入。打开期间禁用路径输入、选择按钮和保存按钮，避免重复打开或保存未完成的选择。编辑路径会清除过期的保存成功提示与错误。

保存继续走现有 `save_download_preferences`，由 Rust 校验已存在的绝对目录，空值仍表示系统下载目录；后端、任务存储与目录校验逻辑未修改。
