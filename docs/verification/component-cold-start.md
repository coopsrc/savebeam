# 官方独立组件的冷启动检测

2026-11-14，macOS Apple Silicon。

真实下载并核对官方发行 SHA-256 后，`yt-dlp_macos 2026.10.26` 的首次 `--version` 用时超过原来的 5 秒。应用将其误判为不健康并回滚；同一文件在约十几秒后可正常报告版本。

yt-dlp 检测改为最多 30 秒，其他组件仍限 5 秒；仍只执行固定版本参数。Unix probe 使用独立进程组，超时时杀死该组并回收，避免 standalone 包的解包子进程持有 stdout/stderr，使 reader join 超过超时。

单元测试以 `/bin/sh` 启动继承管道的 60 秒子进程，在 100 ms 检测预算后返回 TimedOut，实际约 120 ms，防止只杀父进程造成长期等待。

真实 macOS arm64 官方 yt-dlp 2026.10.26 和 Deno 2.9.8 使用新的冷启动预算，通过 SHA-256、真实 HTTPS 取消/临时文件清理、仅提取目标程序、版本探测、同版本替换及无效新程序回滚验证。所有文件位于本次 `/tmp` 目录，不替换系统/Homebrew/用户组件。签名清单发布和其他 OS/架构的运行验收仍单独保留。
