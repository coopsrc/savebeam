# 任务归档、整组操作及封面缓存

2026-11-11，macOS 开发环境。替代前一版“已完成任务仍显示在任务页”和“没有整组操作”的呈现。

- 任务页只显示尚未成功完成的任务，保留失败/取消以便重试。部分成功的合集两页可同时出现，任务只展开未完成子项；全组成功后只保留历史，补下/更新时再次显示任务组。历史写入失败不再标为成功后隐藏，而保留失败任务；历史页同时监听成品和成功状态变化，避免事件先后顺序漏刷新。
- 共用 `RecordCard` 的封面、标题、摘要和操作排布；任务有进度，历史无进度。合集及多 P 两页均有选择视频入口，回填原来源到完整解析/选择工作区，保留网络选择、独立画质和高级设置流程。
- 整组删除从 Rust 获取全部成员快照，包括搜索未展示的历史/版本，前后端均不接收文件路径。后端确认组键与所有成员归属，拒绝混组、重复、缺失或超出 1000 项的请求。任务先整批取消再等待停止（上限 15 秒），成功/后续新增/其他组不删除；历史默认保留文件，可勾选沿用单项安全规则移入系统回收站。部分失败仅返回已删除 ID，显示错误并保留余项重试，不影响其他组或订阅台账。
- schema v17 新增去重图片和任务引用表。解析时已有封面随创建事务写入；排队/重试快照不带图片，版本和补下可复用缓存。列表只读结构数据，封面在卡片可见后单独按 ID 读取，切换页面不自动联网。无缓存可手动读取，已有图片可主动刷新；失败保留旧图片，迟到的本地读取不能覆盖刷新结果。图片只允许有签名的栅格 data URL，单图解码后上限 4 MiB，总缓存文本上限 64 MiB，LRU 只清图片引用，不删任务或媒体。
- 标题、来源、选择参数、历史/版本和订阅已保存元数据沿用本地持久化；视频列表、格式和字幕的动态结果不视为永久有效，在显式解析/检查时更新。封面刷新不改写下载时的标题、选择和版本证据；不缓存临时媒体直链或原始完整 JSON，不添加后台定时网络请求。
