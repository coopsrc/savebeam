## 实现结果

- 单任务参数由 Rust 固定构造，不加载用户配置、不启用播放列表、不覆盖已有文件；输入 URL 保持单独参数。
- `yt-dlp` 通过 `--progress-template` 输出结构化字段，Rust 转为版本化 Tauri 进度事件。
- 任务状态由 Rust 状态机管理，支持取消、失败重试和应用退出时取消活动任务。
- 成功状态只有在 yt-dlp 返回最终路径、文件真实存在、非空且规范化路径位于所选下载目录内时才会发布。
- 默认输出位置为系统 Downloads 目录；目录偏好和任务持久化由 M5 负责。
