# 下载草稿跨导航保留

日期：2026-10-23（Asia/Shanghai）。

## 根因与范围

下载页原为路由叶子节点，离开 `/download` 会卸载 `DownloadPage`，其中的 useState、详情/匹配 hooks 和未提交输入随之销毁。现在由 AppShell 保持一个已开始编辑的下载工作区，离开时隐藏而非卸载；不引入全站缓存或新的依赖。后续 SETTINGS-DRAFT-T1 也按需保留一个设置工作区，见 `settings-tabs.md`，其余页面仍沿用普通路由。

## 行为边界

- 保留 URL、代理、媒体结果、封面状态、手动选流、列表范围/确认、统一/单项策略、详情/匹配缓存、高级选项、错误提示、页面及列表滚动；已有异步操作可完成，不因返回重复解析/下载或读取全局默认。
- 无编辑的空白页离开后释放，下次读取最新默认；整批成功入队后清理草稿；部分入队失败继续保留剩余范围。任务页明确的来源预填会创建新草稿，保留完整 URL 参数和 fragment，不自动解析，也不复用旧视频信息。
- 草稿是本次窗口运行期的内存状态，不写浏览器存储、文件或数据库；重载/重启不恢复媒体缓存。源格式可能过期，需用户显式重新解析。
- 隐藏页不可访问/聚焦；弹窗在其他页面关闭且不抢焦点，返回继续独立弹窗草稿。显式取消/Escape/遮罩关闭仍丢弃弹窗修改。
- 完成提交时同时校验页面活动状态和发起时的浏览器位置，避免路由过渡尚未提交时抢回导航；回调只消费原会话身份，防止旧回调影响新草稿。没有改变 Rust 任务创建和持久化快照。
