# 下载页响应式布局验证

日期：2026-10-22。

## 当前方案

- 单视频始终单列：媒体信息与音轨选择、下载选项、开始按钮。内容宽度最大 820px。
- 系列宽窗口双列：左侧媒体信息、下载选项和开始按钮；右侧为条目列表、订阅入口、全选/取消全选、数量确认。内容最大 1240px，1200px 窗口宽度起启用双列。
- 窗口小于 1200px 时系列改为单列：媒体信息 → 条目列表 → 下载选项和开始按钮。DOM 顺序与视觉顺序一致，键盘操作不跨列跳回。
- “预计输出”整块移除，不再显示预计文件名、大小或格式组合；保存目录/命名规则说明、实际合并容器和文件命名保持原逻辑。
- 系列条目自然换行、不压缩行高，最大高度 `clamp(260px, 48vh, 520px)`，独立滚动；确认框在滚动区域外。封面固定 144×81px，窄窗口封面/标题和链接/按钮分别上下排列。
- 解析表单仅包含 URL 和解析按钮，条目选择、下载选项与开始按钮不再位于解析表单内，避免 Enter 误触发重新解析。

## 自动回归

`scripts/verify-download-layout-ui.mjs` 使用已安装的 Playwright 模块与本机 Chrome，通过固定媒体数据模拟 Tauri IPC；不请求真实视频或读取 Cookie，不引入应用运行依赖：

```sh
node scripts/verify-download-layout-ui.mjs /path/to/playwright/index.mjs http://127.0.0.1:1421/
```

单视频/17 项系列分别覆盖 1600、1280、1200、1199、1100、800、560px，共 14 个场景，验证：

- 单视频始终单列，系列双列断点正确，右侧列表与左侧媒体信息顶端对齐；窄窗口列表位于媒体与开始按钮之间。
- 封面不会被 Image 的默认宽度撑满，标题宽度正常、不会越界；内容区无横向溢出。

- 逐项取消、全选/取消全选、空列表禁用、数量确认及修改集合后撤销确认保持正常。
- 手动音轨入口可用，音视频组合与 MP4 合并参数正确；MP3 切换撤销系列确认并重置音轨选择。
