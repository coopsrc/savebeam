# 下载页响应式布局验证

日期：2026-10-22。

## 当前方案

- 单视频始终单列：媒体信息与音轨选择、下载选项。内容宽度最大 820px。
- 系列宽窗口双列：左侧媒体信息、下载选项；右侧为条目列表、订阅入口、全选/取消全选、数量确认。内容最大 1240px，1200px 窗口宽度起启用双列。右侧卡片顶部对齐媒体信息顶部、底部对齐下载选项底部，高度由左侧卡片及间距决定。
- 开始按钮独立放在单列/双栏下面的操作区，右边缘与内容外边缘对齐，不在选项卡片或列表中，不悬浮遮挡内容。
- 窗口小于 1200px 时系列改为单列：媒体信息 → 条目列表 → 下载选项 → 独立开始操作区。DOM 顺序与视觉顺序一致，键盘操作不跨列跳回。
- “预计输出”整块移除，不再显示预计文件名、大小或格式组合；下载选项底部的全局 Cookie、保存位置和命名规则三段提示也移除。保留 MP3、保留中间文件等选项自身说明，实际配置、合并容器与文件命名保持原逻辑。
- 系列条目自然换行、不压缩行高；双栏通过尺寸隔离（`contain: size`）避免右侧内容参与撑高网格行，滚动区域弹性填充剩余空间。窄窗口列表最大高度 `clamp(260px, 48vh, 520px)`。两种布局均独立滚动，确认框在滚动区域外。封面固定 144×81px，窄窗口封面/标题和链接/按钮分别上下排列。
- 解析表单仅包含 URL 和解析按钮，条目选择、下载选项与开始按钮不再位于解析表单内，避免 Enter 误触发重新解析。
- 开发平台切换控件移到顶部标题栏；修复了它在底部浮层位置遮挡独立开始按钮、拦截鼠标点击的问题。正式构建不显示该控件。
- 右侧列表仍使用原生滚动，局部样式为透明轨道、8px 槽宽和圆角细滑块，不再出现突兀的浅色框形轨道；滑块颜色随明暗主题变化，文字与滑块之间留出间隔。列表可键盘聚焦，空/短列表没有可滚动内容时不显示滑块。

## 自动回归

`scripts/verify-download-layout-ui.mjs` 使用已安装的 Playwright 模块与本机 Chrome，通过固定媒体数据模拟 Tauri IPC；不请求真实视频或读取 Cookie，不引入应用运行依赖：

```sh
node scripts/verify-download-layout-ui.mjs /path/to/playwright/index.mjs http://127.0.0.1:1421/
```

单视频/17 项系列分别覆盖 1600、1280、1200、1199、1100、800、560px，共 14 个场景，验证：

- 单视频始终单列，系列双列断点正确，右侧列表与左侧媒体信息顶端、下载选项底端对齐（误差不超过 1px）；窄窗口列表位于媒体与开始按钮之间。
- 开始按钮位于独立操作区，始终在卡片下方、右边缘与整块内容对齐。
- 封面不会被 Image 的默认宽度撑满，标题宽度正常、不会越界；内容区无横向溢出。
- 17 行列表不重叠、能滚动到末项、不会覆盖确认框；预计输出/大小/文件名区域不存在。
- Cookie/保存位置/命名规则三段提示不存在，MP3 选项自己的 FFmpeg 说明仍存在；左栏变短后右栏继续上下对齐。
- Chrome 中验证滚动条宽 8px、轨道透明、滑块圆角 8px；键盘 End/Home 可滚动到末尾/开头，滚轮滚至末项时页面自身不跟随移动。测试关闭浏览器平滑滚动，避免在原生滚动动画尚未结束时发送相反按键造成竞态。
- 逐项取消、全选/取消全选、空列表禁用、数量确认及修改集合后撤销确认保持正常。
- 手动音轨入口可用，音视频组合与 MP4 合并参数正确；MP3 切换撤销系列确认并重置音轨选择。
- 保留中间文件参数继续传入；系列提交除第 2 项外的 16 个原始索引，解析和创建任务均各调用一次，无 pageerror。
