## 实现

- yt-dlp 元数据检查使用 `--flat-playlist --playlist-end 51`，限制检查阶段枚举的条目数。
- 播放列表最多允许创建 50 项的下载任务；若上游提供确切总数，则显示确切数量，否则通过第 51 项判断是否超过上限。
- UI 要求用户明确勾选确认后才允许创建列表任务；超限列表仅下载前 50 项。
- 单视频继续显式传入 `--no-playlist`；播放列表使用 `--yes-playlist --playlist-items 1-N`。
- 任务的列表数量选项持久化，重启恢复后继续使用相同范围。
- 后端命令与参数构造再次验证 1–50 范围，不信任仅靠前端约束。
