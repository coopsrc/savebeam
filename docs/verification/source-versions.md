# 来源变化提示与历史版本

日期：2026-10-23（Asia/Shanghai）。任务 SOURCE-VERSION-T1。

## 行为与安全边界

- “历史”和已完成任务新增“来源与版本”，本地读取不访问站点，完成后点击“刷新版本”更新列表。检查由用户点击触发，代理默认不勾选，Cookie 使用已有全局授权；变更代理后清除旧检查。后端创建新版本前再次检查，媒体 ID/extractor 或预期系列 ID 改变时拒绝，避免重排后下载错条目。
- 时长、修改时间、cid、可用格式白名单摘要的差异仅表示疑似变化。临时地址、头、标题和格式顺序不纳入。旧任务只补记本地成品摘要，不将当前来源伪装成旧基线。没有可比字段则未知，无变化也不是内容保证；站点可能不提供可靠版本字段。
- 新任务在根下载目录 `Savebeam Versions/根任务ID/v-唯一值/` 保存，内部遵循原命名；旧文件不移动/重命名。强制 Skip，原高级快照与策略保留，但重新匹配当前格式 ID；旧单视频无策略时用自动推荐，而非保证复用旧手选编码。排队恢复及失败/取消重试继续使用同一版本目录和任务快照。
- v13 保存父任务、来源观察和最终成品 SHA-256。文件按 64KiB 流式读取，拒绝缺失、符号链接及下载目录外文件，Unix O_NOFOLLOW/inode 校验；不能安全读取或文件在读取中变化时摘要未知。字节不同也可能是编码、封装或元数据变化，不证明换源。
- 历史删除事务删除该条版本摘要，其他版本不受影响。原文件删除仍默认不勾选，只处理记录成品，不扫描字幕/封面/JSON/分轨，不删除目录。任务视图删除仍不删除历史和文件。
- 来源投影独立于完成 ID 记录，来源行最多 128KiB、记录最多 50 条；超限不影响独立的成品完成验证。显式版本操作最多一个后台实例。普通系列创建/估算的 50 项范围不变；历史检查可针对一个订阅序号（1–1000），且下载仍用精确 ID guard。
