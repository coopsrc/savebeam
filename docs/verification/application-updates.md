# 应用更新与关于页验证

日期：2026-11-14；macOS Apple Silicon。

- 显式检查固定 GitHub Release `latest.json`，不在启动或进入设置时联网检查应用更新。服务端保存待更新对象，前端安装只接受已检查版本号，不能指定包 URL/密钥。
- 独立 Minisign 公钥，要求签名绑定版本；不复用组件清单 Ed25519 密钥。下载仅 HTTPS、限制 256 MiB、支持进度与取消；验签后才安装。更新操作互斥，检查前清除旧结果；失败释放操作锁。
- 安装前由下载仓储原子关闭新建/重试入口，存在未完成下载则拒绝安装；安装失败恢复入口。开发版本拒绝安装，避免替换正在开发的应用。
- 关于页提供版本/平台、原文发行说明、离线中英文政策/条款、Apache-2.0 许可证及延迟加载的第三方声明。问题反馈只打开固定 GitHub 表单，不附加诊断/媒体信息；基本信息只含版本/平台/架构。
- Rust 测试覆盖更新互斥、固定配置、任务保护与失败解锁；既有队列测试继续执行。浏览器 `verify-app-update-ui.mjs` 中英文通过：无自动检查、无更新、可用更新、纯文本 notes、取消确认、失败清除旧数据、进度、取消、安装只发版本、进行中任务阻止安装、四种政策弹窗、反馈目标。
- 前端 lint/build、70 个单元测试和 Rust Clippy 通过；设置 Tab 回归另见执行记录。

发布边界：本机没有 Developer ID/公证或 Windows 代码签名凭据。尚无已公开的更新包，未对用户当前安装执行替换/重启。UI 使用 IPC fixtures，不代表真实服务器更新、原生安装与跨平台验收已通过。完整第三方 notices 来源审计在发布审计中独立记录。
