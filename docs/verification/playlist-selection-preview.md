# 系列条目选择与预计文件名

日期：2026-10-22。

后续调整（2026-10-22）：按用户最新要求移除预计输出区域，单视频单列、系列右侧列表。本文的预览界面与相关验证为历史记录，不再代表当前布局；条目选择和后端命名规则不变。当前验收见 [下载页布局验证](download-responsive-layout.md)。

## 交互方案

- 单视频的预计输出显示 `标题 [视频ID].后缀`，后缀随合并容器或 MP3 选择更新。长名最多两行，悬停可查看完整文本。
- 系列先显示逐项复选框、全选/取消全选、已选数量和数量确认。默认选择当前可选条目，改变集合或切换 MP3 后重新确认。未选中任何条目时不可开始。
- 系列的预计输出显示 `系列名称 [系列ID]/`、已选数量及独立滚动的文件名列表，例如只勾选 1、3、5 时显示 `1-第一课 [v1].{扩展名}`、`3-第三课 [v3].{扩展名}`、`5-第五课 [v5].{扩展名}`。序号不重新排列成 1、2、3。
- 轻量解析不读取每一项全部格式，故系列一般格式与合计大小仍待逐项解析；MP3 后缀已知。预览只清理常见特殊字符用于展示，不作为输出路径提交，下载时 yt-dlp 的完整清理、实时标题和实际后缀仍为准。
- 预览仍紧邻开始按钮上方，单视频 200px、系列 340px 最小高度。系列文件列表固定 128px 内部滚动；改变数量、空选择和 MP3 不使面板上下跳动。

## 后端与持久化

沿用前 50 项安全上限，不增加任意范围或无限列表读取。轻量解析返回原始索引、标题、可选状态与可空 ID，不返回媒体 URL、请求头或 Cookie。空项、重复索引、嵌套列表或源索引大于 50 的条目不可选；有视频链接但尚无 ID/标题时显示待解析。旧后端没有 entries 字段时不白屏、不虚构选择，提示重新解析。

`DownloadOptions.playlistItems` 为可空序号数组，`playlistItemCount` 表示所选数量。创建任务和构造 yt-dlp 参数均校验数量与数组一致、非空、唯一、每项位于 1–50；先排序再生成 `--playlist-items 1,3,5`，不拼接任意用户字符串。全局 Cookie、格式选择和其他后处理选项保持原行为。

SQLite v8 添加可空 `playlist_items_json`，数据库往返、重启恢复和失败重试保持原数组。旧行 NULL/旧客户端缺省数组，仍使用原来的 `1-N` 规则，单视频不得带系列数组。
