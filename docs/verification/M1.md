## 功能验收

- 四个主导航页面可由 HashRouter 路由访问；紧凑侧栏为图标链接保留可访问名称。
- 下载页 URL 校验仅检查格式，不联网、不读取剪贴板；有效链接可进入明确标记的模拟媒体信息和格式选择。
- 创建模拟任务后可在任务页看到 URL、格式和模拟排队状态。模拟数据仅存在前端内存，不启动进程或写入历史。
- 开发环境可在“自动 / macOS / Windows / Linux”间切换 profile；生产构建不显示切换控件。
- `Meta+1…3` 或 `Ctrl+1…3` 切换主要页面，平台修饰键加逗号打开设置；快捷键不会在输入控件获得焦点时抢占输入。
- 提供跳过导航链接、可见焦点样式、表单标签、状态组件 live region，并把文档语言声明为简体中文。

## 已知限制

- 这是交互原型；媒体解析、实际下载、组件状态检测尚未接入。
- Windows/Linux profile 可在开发环境强制预览，但本次没有在 Windows/Linux 原生桌面环境运行，也没有独立截图基线。
- 最小窗口和键盘操作通过断点、语义和构建检查审查；尚未完成真实辅助技术（VoiceOver/NVDA）验收。
- `pnpm check` 不代替人工检查窗口装饰和系统原生交互；正式发布前仍需逐平台验收。
