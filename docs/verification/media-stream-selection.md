# 视频和音频独立选择验证

日期：2026-10-21。

## 交互与下载

- 默认预选视频画质，并自动匹配音轨；不会从混合格式列表的第一项默认选中纯音频。
- “手动选择音频”默认关闭。勾选后展开音频列表，显示编码、码率、语言和原始格式 ID，并标注“推荐 · 自动匹配”或“兼容推荐”；取消后恢复自动匹配。
- 页面实时展示预计输出扩展名和视频/音频编码。自动模式优先选择适合原视频容器的音轨；手动改变编码可能改变输出容器。合并保留原始编码，MP3 模式为明确的音频转换操作。
- 单独的流组合以 `videoId+audioId` 交给 yt-dlp；实际 `--merge-output-format` 与 UI 显示的 MP4/WebM/MKV 一致。音频转换尊重选定源格式，不再无条件覆盖为 `bestaudio/best`。
- 音视频一体格式使用原始容器和内置音轨；此时“手动选择音频”禁用，并说明需选择分离格式才可更换独立音轨。
- SQLite schema v6 新增 `merge_container`，随任务保存合并容器；旧任务默认为空，继续使用原下载行为。播放列表按项自动选择音视频。

组合及合并依据：[yt-dlp 格式选择说明](https://github.com/yt-dlp/yt-dlp#format-selection)。

## 自动化结果

`pnpm tauri build --debug --no-bundle` 通过，生成 macOS 本机 debug 可执行文件；新增的码率、语言和格式备注映射断言也通过定向 Rust 测试。
