# 高级设置与下载选项默认值

日期：2026-10-22。

后续字幕交互已改为可搜索的多选下拉框及标签，当前方案见 `subtitle-selection.md`；本页的输入代码行为仅是之前阶段的记录。

## 行为

- 主界面只保留媒体信息、音视频选择、系列列表及底部操作行，原下载选项卡片移除。高级设置按钮与开始下载同组、位于右侧，窄窗口换行后仍右对齐。系列双栏媒体与列表等高、列表独立滚动。
- 高级设置包括音频模式、字幕语言/自动字幕、封面、JSON、元数据和中间文件；弹窗草稿只有应用后生效。取消、Escape 或遮罩关闭不保存；恢复全局默认仅更新草稿，需要再应用。
- 设置页“下载选项”保存新任务默认值，可恢复初始草稿再保存。保存失败保留输入，读取失败明确提示并允许重试；用户可显式恢复初始草稿再保存修复损坏值，不偷偷换成全关配置。
- 下载页默认值只在进入页面时加载，重新解析/切换代理保留本次已应用设置。仅音频来源自动切为音频模式；字幕代码可输入或从解析值选择，语言为空时关闭自动字幕。
- 订阅批量下载使用同一弹窗；一批的配置投影到每个任务。订阅下载 IPC 未提供下载选项时，在创建本批任务前一次性读取默认值。

## 生命周期与兼容

`download.option_defaults` 仅保存在 `app_settings`。任务创建时将选项复制到已有 `download_tasks` 列，后台下载从任务持久化参数运行，不查询默认值；任务的排队、下载/后处理、取消、失败、重试、重启恢复及完成记录均保留相同选项。SQLite schema 仍为 v11，不重写旧任务、历史或文件。Cookie、代理地址和队列并发的原有全局/任务规则不变。

Rust 生命周期测试使用独立文件数据库：保存全开默认值，创建含 JSON 单独关闭的排队、准备、取消、完成任务，将全局默认改为全关，然后关闭重开数据库。验证各条任务全部选项相同，排队领取、失败/取消重试仍用旧快照，生成参数保留 MP3、字幕/自动字幕、缩略图、元数据、中间文件，不重新打开 JSON。另测全局默认值文件重开、非法保存不破坏上次配置及损坏值不静默重置。
