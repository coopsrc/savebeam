# M7-T2：音频、字幕、缩略图与元数据选项

- 状态：任务级实现与自动化验证通过；M7 整体未验收。
- 检查日期：2026-10-21
- 执行平台：macOS Apple Silicon

## 实现

- 下载界面提供 MP3-only、字幕语言、多语言自动字幕、另存缩略图、另存媒体信息 JSON 和嵌入媒体元数据选项。
- 仅音频固定使用 `bestaudio/best` 与 `--extract-audio --audio-format mp3`；此选项要求可用的 FFmpeg 和 ffprobe。
- 字幕语言仅从解析结果选择；Rust 参数层限制数量和字符集，并以 argv 传递，不经 shell 展开。自动字幕必须至少选择一种语言。
- 所有选项均作为下载任务参数持久化，任务重启恢复时保留原配置。
- 参数映射遵循 yt-dlp 官方 README 中的音频提取、字幕、缩略图和元数据选项说明：[yt-dlp README](https://github.com/yt-dlp/yt-dlp#post-processing-options)。
