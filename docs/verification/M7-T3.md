# M7-T3：用户授权的全局 Cookie 来源

- 状态：任务级实现与自动化验证通过；M7 整体未验收。
- 检查日期：2026-10-21
- 执行平台：macOS Apple Silicon

## 实现

- 在“设置 → Cookie 与登录”配置不使用登录信息、指定 `cookies.txt`，或从本机浏览器读取 Cookie；具体配置选择遵循 yt-dlp 默认行为（通常选择最近使用的配置）。
- 经用户明确授权后，设置对媒体信息解析和下载全局生效；下载任务仅引用全局设置，不在任务数据中复制 Cookie 来源或凭据。
- 文件选择使用 Tauri 原生文件选择器；后端只校验路径和扩展名，不读取或复制 Cookie 内容。
- 浏览器来源为固定白名单（Brave、Chrome/Chromium、Edge、Firefox、Opera、Safari、Vivaldi、Whale）；不允许传入任意浏览器标识或 profile 参数。
- 两种来源互斥。UI 展示账号权限风险说明，并要求用户逐任务明确勾选授权；Rust 命令和 argv 构造再次校验授权。
- 明确告知 `cookies.txt` 会被 yt-dlp 读取且可能写回更新；建议用户不愿修改源文件时选择副本。
- `--cookies` / `--cookies-from-browser` 均通过独立 argv 参数传递，不经过 shell；普通日志不记录 argv。应用设置仅保存来源/路径和授权状态，不保存 Cookie 内容。
- 下载任务记录可在恢复/重试时复用已授权来源。
