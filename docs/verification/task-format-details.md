# 任务音视频参数可读性

2026-11-12，macOS 开发环境。

- 将任务卡片主要区域的 `格式：100143+30280` 改为视频/音频两行。例如 `视频：1920×1080 · 29.97 FPS · HEVC · 1266 kbps · MP4` 和 `音频：AAC · 128 kbps · M4A`；技术格式 ID 留在悬停说明。字体由 xs 调整为 sm，长内容正常换行。
- 保存当前选择的最小参数快照：单视频由解析结果生成，合集/多 P 根据实际匹配 ID 捕获，手动版本重下重新匹配并更新快照。schema v20 添加可空列，旧记录保持为空，状态与执行选项不改写；快照随任务持久化、恢复与重试保留，切换界面语言重新生成文案。
- 无快照的旧任务显示“此旧任务未保存音视频参数”；自动选择任务显示下载时确定，不将站点 ID 映射为固定编码/分辨率。MP3 只明确输出格式，另外标注源音频，避免冒充最终转码码率。元数据缺少的字段省略。
- 快照没有媒体 URL、请求头或 Cookie，字段长度和数值有边界，不参与下载命令构造，不新增站点请求。
