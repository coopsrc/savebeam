- SQLite 使用 bundled 构建，存放在 Tauri app-data，由 Rust Repository 独占访问；数据库损坏时初始化错误可返回给 IPC，不会直接使启动过程 panic。
- 首次下载时默认目录使用系统 Downloads；用户可配置一个已存在的绝对路径。当前设置页使用路径文本输入，尚无原生目录选择器。
