# M7-T5 验证记录：CSP 与 Tauri capability

## 已实现

- 启用 CSP：默认只允许本地内容/Tauri asset，脚本仅 `'self'`；connect 仅开放 IPC 和本地 Vite 开发服务器；没有远程脚本或通配网络源。
- 因 Mantine 动态样式保留 `style-src 'unsafe-inline'`；图像仅允许本地 asset、blob 和 data；禁止 object、限制 base/form。
- 主窗口 capability 移除 `core:default`、`opener:default`，仅保留前端实际使用的事件 listen/unlisten 和原生对话框 open/save/message。
- 未引入 Shell、Filesystem 或 Process 插件权限；应用自定义命令仍由 Rust 固定命令表显式注册。

## 验证

- `pnpm tauri build --debug --no-bundle`：通过，Tauri 接受 CSP 配置和 capability 权限并生成 macOS debug app。
- 人工盘点 `src` 的 Tauri API 使用，只发现 IPC invoke 与事件 listen/unlisten；文件选取、保存、消息由 dialog 插件处理。

## 尚未验证

- 未在运行中的 GUI/WebView 手动执行下载、Cookie 文件选择、诊断导出、历史文件打开和外部链接全流程，仍需人工 smoke test 观察 CSP console 报告。
- 当前 CSP 为跨平台共用；如未来各平台 WebView 的本地协议差异导致阻断，应按平台收窄/补充精确源，而不是添加通配来源。
