# 系列画质、标题和逐项大小

日期：2026-10-23（Asia/Shanghai）。

## 产品方案

- 默认窗口/最小窗口 1280×800，系列双列：左上媒体信息自然高度、左下统一策略，右侧列表与左侧整体上下对齐；列表内滚动，开始按钮/高级设置保留底部右侧。浏览器窄窗降级仍保留以防溢出，但不是原生允许的最小尺寸。
- 统一分辨率（高度）、视频码率和音频码率上限，各项在自己格式中匹配，不复用另一个视频的格式 ID。缺档向下，不匹配则跳过；允许超限必须明确勾选并有行内提示；少数例外可单独覆盖/恢复统一策略。
- 每行提前显示标题、ID、实际分辨率、视频/音频 kbps、约大小及覆盖/回退标识。分轨求和、含音轨视频计一次；缺失参数不冒充已知数值，MP3 转换大小待定。底部只汇总勾选且匹配的条目，部分已知不叫完整总量。
- 初次快速列表后按最多 5 项一批自动补读元数据，最多前 50 项；用户可停止后续读取/重读。不下载媒体、不访问未确认的 Cookie 来源，沿用本次代理选择。策略变化只用当前详情缓存重新匹配。
- 详情读取失败/缺失/重排 ID 不匹配有明确行内错误，不承诺任何站点始终提供标题。当前请求有 60 秒/16MiB 限制，JSON 部分成功时不会一起丢弃可用项。

## 快照与队列

Rust 预览和任务创建调用同一个匹配器。每项独立任务固定 format ID 组合、merge container、原始 playlist index、预期 ID、有效策略、高级设置和代理选择。SQLite v12 添加 nullable `quality_policy_json`；旧任务 NULL，不覆盖其原选项。恢复、重试、完成记录均保留旧快照，不因后来策略变化自动改档。源格式后来消失时需重新读详情后新建任务，不能静默下载不同规格。

开始前确认实际匹配数和将跳过数，全不匹配不能提交。服务端校验 URL、1–50 原始索引/唯一性、ID/标题/格式数量/策略范围/覆盖索引，拒绝进行中的重复条目；列表重排时下载参数的 ID 过滤避免取错视频。部分任务创建失败只返回已成功加入的序号，前端保留未加入条目便于处理，不对已创建任务重复提交。既有同名文件仍按设置中的跳过/覆盖策略处理，不强制覆盖。

## 自动验证

- `pnpm check`：32 个前端、143 个 Rust 单测，格式/ESLint/Clippy/TypeScript/Vite 通过（保留既有大包提示）。
- Rust：不同视频各自匹配、码率/高度上限、未知值不匹配、明确超限回退、muxed 不双计、MP3 未知、单项覆盖、标题/原始序号投影、ID 改变/缺失、策略和输入范围、固定任务参数、v12 策略回读及整个任务生命周期。
- `verify-playlist-quality-ui.mjs` 五组：统一策略+覆盖/取消；未匹配跳过；读取失败与恢复；停止后续批次；换链接的旧响应不回填。验证策略变化不增加详情请求、行内标题/大小、确认与任务快照、1280×720 和双栏自然媒体高度。
- `verify-download-layout-ui.mjs`：单/系列、宽/窄浏览器、0/1/50 项、长标题、滚动条端部、暗色、开始按钮及高级设置参数；系列新批次 IPC 断言独立于单视频路径。
- `verify-download-size-ui.mjs`：单/系列 × 代理/直连、部分未知、完整总量、MP3、重读与恢复；高级设置及订阅既有 UI 脚本回归。

脚本形式：`node scripts/<script>.mjs <playwright/index.mjs> http://127.0.0.1:1421/`，全部为本机 fixture，不改变用户设置或下载文件。

## 真实 yt-dlp 验证

1. `verify-playlist-quality-ytdlp.mjs`：使用安装的 yt-dlp 2026.8.19，以本机 info JSON 和 `--simulate --skip-download --no-check-formats` 验证 Rust 测试确定的 `lower+a128`、`higher+a256`、`a128` 确实解析为相同流 ID，下载前标题可得；不访问网站、不下载媒体。
2. 对用户提供的 B 站合集 `https://space.bilibili.com/306979414/channel/collectiondetail?sid=6546672` 只请求第 1 项，`--no-flat-playlist --playlist-items 1 --skip-download --ignore-no-formats-error`。使用显式直连、无 Cookie/浏览器登录读取，返回 `BV1Zz4y1H7wQ`、完整标题与 15 个格式；没有下载视频。证明该示例可提前补标题，不等同于整个合集所有项或全部登录画质已验收。

2026-10-23 后续调整：默认和最小窗口高度从 720 改为 800，窗口配置单测和后续 UI 回归脚本同步为 1280×800。以上 1280×720 的 UI 验证及截图保留为此前结果，不作为新尺寸的实机验收。

原生窗口尺寸限制和跨平台交互仍需重新启动 Tauri 后实机确认。浏览器/离线验证不代表每个公网视频可下载。此前截图：`/tmp/savebeam-playlist-quality.png`、`/tmp/savebeam-playlist-quality-1280x720.png`。
