# 历史与订阅页面会话保留

日期：2026-10-23（Asia/Shanghai）。

## 实现与边界

- 原历史/订阅路由会卸载页面，现在由 AppShell 首次访问后各保留一个实例。与设置一样，进入前不挂载；保留路由集合最多三个，下载仍使用原来的单实例草稿生命周期，任务保持普通路由。没有新增依赖或后端/数据库改动。
- 保留历史的搜索框草稿、已提交查询结果、错误/提示，以及订阅的添加链接、显示已下载开关、展开条目、勾选 ID、代理、高级下载选项、当前操作结果。选择仍按本地实际可下载状态过滤，已入队/完成不会被误当成可重复提交项。
- `useRetainedPageScroll` 仅在活动页挂载共享内容区 scroll 监听，隐藏时移除；其他页面滚动不覆盖缓存。条目列表 DOM 也保持挂载，内层位置随之保留。缓存仅在本次运行中有效，不写浏览器存储或文件，重载/关闭/重启清除临时状态。
- 历史删除、取消订阅和高级选项弹窗在离开时关闭可见性且不返还焦点，返回后恢复草稿；显式取消仍丢弃弹窗修改。切换导航不会删除文件、取消订阅或创建任务。
- 历史成品事件在保存记录之后发出，仍触发本地读取，沿用已提交查询而非尚未提交的搜索输入；请求身份隔离迟到响应。删除成功刷新也使用已提交条件。订阅任务变化仍同步本地列表与历史系列候选，不触发视频网站请求。
- 订阅单项检查可在离开后完成；检查全部离开后停止后续项，维持原有有界手动检查规则。返回不重新触发检查。下载页“订阅此系列”携带新的显式 URL 时仍只回填输入，不重置其他系列选择或自动订阅。

- 跨下载/任务/设置/历史侧栏往返，断言历史 600px、订阅 650px 外层和订阅条目 140px 内层滚动独立恢复；未发生因导航导致的历史/订阅目录重读、检查或下载。
- 快捷键离开并返回删除历史、高级选项、取消订阅弹窗：不可见期间不残留对话框或抢焦点，恢复勾选/未应用草稿，取消不执行写操作。
- 验证隐藏期间单项检查完成后保留选择；全部检查只完成当前 1/3 后停止；新的显式系列来源回填保留完整参数和 fragment、不自动检查。返回后准确入队 2 个原选中 ID，代理与已应用保留中间文件选项进入快照，取消的缩略图草稿未进入任务。

- 对历史构造迟到查询，离开再回来发起新查询后放行旧响应，验证旧结果不会覆盖新结果。
