# 本地系列订阅验证

日期：2026-10-22；环境：macOS Apple Silicon。

## 范围

左侧“订阅”入口与修饰键 + 4；从已完成系列或链接添加；按稳定视频 ID 检查新增；手动选择下载；重排保护；取消订阅不删除文件。无后台检查或自动下载。技术边界详见设计说明书 §9.5。

- `pnpm check`：格式、ESLint、Clippy、TypeScript/Vite、21 个前端及 109 个 Rust 测试通过；Vite 保留现有大于 500 kB 的主包提示。
- Rust 新增测试：首次基线不假记下载、重排只更新位置、新增 ID、完整/不完整扫描、来源变化事务回滚、完成台账与取消订阅分离、失败/排队不记完成、任务 ID guard/999 序号持久化、1000 项边界、B 站多 P、最终路径与预期 ID 验证、最小 stdout ID 投影解析、过滤器元字符编码。
- `node scripts/verify-subscriptions.mjs /opt/homebrew/Cellar/yt-dlp/2026.8.19_2/libexec/bin/python`：真实 yt-dlp 选择第 72 项，列表重排时拒绝错误 ID；引号、`&`、Unicode/emoji 不改变匹配逻辑；隔离临时目录内使用测试专用 file URL 传输测试字节，验证真实 `after_move` ID/最终路径、系列原序号文件名与跳过已有文件的完成输出。没有访问外部网站，不验证真实媒体编解码。
- `node scripts/verify-subscriptions-ui.mjs /tmp/savebeam-ui-regression.iIJjBw/node_modules/playwright/index.mjs`：Chrome fixture IPC 覆盖只选新增后取消其中一项、准确提交 `mediaIds: ["v72"]`、排队后不可重复选择、已下载只读、检查失败保留旧计数/时间、截断提示、预填并添加、取消订阅确认与无文件删除调用。五种场景无 pageerror。脚本支持指定 Playwright 模块及 Vite base URL，不引入应用依赖；默认使用本机 Chrome 路径。
- 既有 9 个单视频/系列选择和文件名预览浏览器场景回归，200px/340px 摘要预留高度保持不变。

## 人工观察

已查看 fixture 订阅页截图，确认侧边栏、系列状态计数、选择操作、独立滚动列表与确认流程的布局。浏览器测试通过 IPC fixture，不代表原生 WebView 或真实网站端到端下载验收。

## 限制与后续验收

- 真实持续更新系列需要用户提供 URL 后进行兼容性测试；本轮未读取 Cookie 或访问账户内容。要求站点 flat 元数据可提供稳定 ID；不支持缺失/变化的任意站点 ID 推测。
- 首次订阅按当前列表建基线；历史成品无 ID、历史已删除或同一系列使用不同 URL 时，可能无法反查旧下载。页面会保留为待下载，不能把未知状态认定为已下载。台账记录曾经下载成功，不跟踪用户后续移动/删除文件。
- 普通批量进程部分失败不登记本批完成 ID，保守地保持待下载；不按序号猜测完成。不提供重置“已下载”标记按钮，重新下载可使用下载页。
- 单次最多检查前 1000 项；不完整时明确提示，不保证发现范围外的新内容。每批最多选择 50 项，逐项任务受现有 1–4 并发限制。检查全部可停止后续项，当前检查受约 60 秒超时保护；离开页不继续检查剩余系列。
- Windows/Linux 原生运行、VoiceOver、长时间更新/重排、真实 FFmpeg 合并仍需人工或平台 CI 验收；没有公开发布、推送或更改 GitHub Secret。
