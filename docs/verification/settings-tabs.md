# 设置页顶部分组标签

日期：2026-10-23（Asia/Shanghai）。

## 设计与范围

- 参考用户截图的分段标签结构，而非增加导航层级或另一套 UI 库。五组为下载、网络与代理、Cookie 与登录、运行组件、隐私与诊断。没有创建尚无功能的关于/应用更新空页。
- 下载组包含目录/并发/重名策略及全局下载选项；其他各组保留既有表单、测试连接、敏感授权、安装/更新和诊断确认。
- 标签在 `.page-content` 内 sticky，内容最大宽 1100px；最低桌面窗口 1280×800 同排显示，窄预览可横向滚动标签。
- 面板保持挂载，显式使用 `keepMountedMode="display-none"`，避免隐藏 Activity 暂停/重启 effects 导致重复读取、重检或中断安装事件监听。切组不保存、更改默认或触发网络测试；隐藏控件不可访问/聚焦。每组独立记录与恢复外层滚动位置。
- 只保证同一次设置页面挂载期间的草稿保留；离开设置路由或重启后读取已保存配置。没有新数据库、浏览器存储或后端更改。

## 验证

- `verify-settings-tabs-ui.mjs` 覆盖目录、全局下载选项、代理、Cookie 授权、自定义组件路径的未保存草稿跨组保留；下载/组件独立滚动恢复、顶部固定、隐藏控件不可访问、保存失败/异步成功后返回可见，切组不隐式保存/重新加载。
- 验证方向键激活、Home 定位后 Enter 激活；开发 StrictMode 初始双 effect 计数作为基线，不误判为切组重复加载。
- 三平台 profile × 明暗主题 × 五组，共 30 个 1280×800 预览场景，检查标签同排、不越界、只有一个可访问面板。截图 `/tmp/savebeam-settings-{macOS,Windows,Linux}-{light,dark}-{0..4}.png`。
- 附加 800/560px 窄预览依次切换五组，不产生页面水平溢出；选中标签的实色背景、白字及无残留下划线也在悬停状态下检查，避免组件默认样式覆盖。
- 原有 `verify-network-proxy-ui.mjs` 增加进入网络标签的步骤；默认值与高级设置回归继续使用默认下载组，无需改变原来的保存/恢复语义。
- `pnpm build`、`pnpm lint:frontend`、41 项前端测试、全库 Prettier 与 diff 检查通过；保留既有 Vite 大包提示。原有代理七组、高级下载/默认值/草稿七组及侧栏十二场景通过。未改 Rust，未重跑 Rust 编译与测试。

浏览器 fixture 不访问真实 Cookie、代理或视频网站，不安装组件，不修改本机设置；不替代 macOS WebView 与 Windows/Linux 原生验收。
