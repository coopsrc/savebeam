# 通用偏好与中英文界面

2026-10-23，macOS 开发环境。

## 命名和范围

“通用”比“应用设置”简短，适合主题、界面语言及未来窗口偏好。分组为通用、下载、网络与代理、Cookie 与登录、运行组件；既有首次下载组及导航保留语义不变。经用户确认，移除“隐私与诊断”独立 Tab，将诊断导出放入通用底部，不删除内部命令，也不放宽确认、系统保存对话框或数据字段。

主题支持 system/light/dark，语言支持 system/zh-CN/en-US，均默认为 system。跟随系统实时响应，显式设置优先；未支持的系统语言回退英文。偏好使用经过枚举校验的本机 localStorage 键 `savebeam.ui-preferences.v1`，仅 theme/language。损坏/不可读回退有提示，写入失败不应用新值。不是媒体、下载草稿或 SQLite 任务配置的新存储位置。

本地中英词条覆盖下载/质量/高级设置、任务、历史/版本、订阅、组件和公共状态/导航。没有使用在线翻译、DOM 文本扫描替换或任意 HTML；编号占位符按字面插值。媒体标题、链接、文件名、站点内容、日志和字幕语言代码不翻译。日期按界面语言显示，不改时间戳或时区。英文后端错误使用稳定错误码说明；源站/工具返回说明不自动翻译，已有临时反馈可以保留产生时语言。

## 验证

- ESLint、TypeScript/Vite、格式与 `cargo check --all-targets`；前端 61 项，包括所有静态 t 词条覆盖、占位符完整、字面用户参数、偏好损坏与非法类型拒绝、系统语言匹配。Rust 未改动，未重复全量 Rust 测试；保留既有大包提示。
- `verify-app-preferences-ui.mjs`：主题即时切换、随系统明暗、显式选择、简中/英文、HTML lang、系统语言匹配/变化、重载恢复、损坏与存储写入失败；下载 URL 和未保存目录跨语言保留、多个页面英文导航及设置 Tab 保留；诊断入口位置、取消不导出、确认后仅将所选路径传给原命令。
- 既有中文 UI 回归显式固定 zh-CN 浏览器环境。设置页三平台明暗/键盘/草稿/滚动、页面导航保留、12 个系列/多 P 场景、普通/列表自适应布局、高级下载、组件提示/安装指引、任务操作及历史版本脚本通过。

UI 使用隔离浏览器存储和 IPC 模拟数据，不读取用户 Cookie/数据库，不下载媒体或实际导出文件；没有重载用户正在编辑的应用窗口。主题和英文在原生 macOS WebView、Windows/Linux 原生环境仍需手动验收。
