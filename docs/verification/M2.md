## 行为验收

- 查找顺序为用户自定义路径、应用管理目录、常见系统目录、当前进程 PATH；系统/自定义文件不会被覆盖。
- macOS 常见路径明确包含 `/opt/homebrew/bin` 和 `/usr/local/bin`，Finder 启动时不依赖交互式 shell 的 PATH。
- JavaScript runtime 同优先级下 Deno 优先；固定版本参数执行有 5 秒超时、16 KiB 输出上限，不经过 shell。
- JS runtime 下限依据 yt-dlp EJS 文档：Deno 2.3.0、Node.js 22.0.0、Bun 1.2.11–1.3.14（弃用）、QuickJS 2023-12-09；QuickJS-NG 不设最低版本。
- 组件页提供重新检测、自定义绝对路径、恢复自动检测、路径/版本/健康状态展示和手动命令复制。
- 安装命令只展示/复制，不由应用执行；组件下载和更新留待 M6。

包管理器命令已按上游资料核对： [Homebrew yt-dlp](https://formulae.brew.sh/formula/yt-dlp)、[Homebrew FFmpeg](https://formulae.brew.sh/formula/ffmpeg)、[Homebrew Deno](https://formulae.brew.sh/formula/deno)、[yt-dlp WinGet manifest](https://github.com/microsoft/winget-pkgs/tree/master/manifests/y/yt-dlp/yt-dlp)、[Gyan FFmpeg WinGet manifest](https://github.com/microsoft/winget-pkgs/tree/master/manifests/g/Gyan/FFmpeg)、[Deno 安装说明](https://docs.deno.com/runtime/getting_started/installation/)及 [Ubuntu yt-dlp package index](https://packages.ubuntu.com/yt-dlp)。Linux 页面明确将 apt 命令标注为 Ubuntu/Debian 示例。
