# 任务操作与删除验证

日期：2026-10-22；平台：macOS Apple Silicon。

## 原因与修复

原任务页仅显示进行中任务的取消和失败/已取消任务的重试；已完成状态没有操作按钮，且文件路径仅来自会话内 result 事件，重启后不恢复。

- 完成任务新增“打开文件”“打开所在文件夹”“查看历史”“重新解析”。
- 新增按 taskId 精确读取一条历史的 IPC，复用既有仓储和打开命令，不新增任意路径打开接口或权限。后端打开操作也改用精确查询，不扫描全部历史。
- 多成品任务提供文件选择，按所选原始 outputIndex 打开。记录缺失时明确说明并禁用文件操作；打开失败保留按钮、显示局部错误，不展示 diagnostic。
- 重新解析只回填原始链接，保留 query/fragment，用户需要手动解析和确认下载；不修改全局重名策略，不自动重新下载，也不实现未确认的版本归档方案。
- 完成、失败和取消任务提供“删除任务”与确认，只设置 SQLite v10 的 `hidden_from_tasks`，不物理删除行、不触发历史外键级联，也不删除文件或订阅完成记录。启动只装载可见任务；任务仓库的全量查询保留旧行供历史和订阅使用。排队/活跃/取消中的任务需先取消；保存失败保留任务。前端清除对应进度/结果并用 tombstone 忽略迟到事件，删除事件同步其他监听视图。

## 验证

- `pnpm check`：Prettier、ESLint、Clippy、TypeScript/Vite、23 个前端测试及 111 个 Rust 测试。
- 新增 Rust 测试验证三种终态可移除、重复移除幂等、内存重建后不再出现、取消任务不遗留可领取队列项、历史/底层任务行/临时测试成品仍保留；排队和各活跃阶段删除被拒绝且状态不变。前端单测覆盖只清理目标项及迟到状态/进度/结果不能复活已删任务。
- `node scripts/verify-task-actions-ui.mjs /tmp/savebeam-ui-regression.iIJjBw/node_modules/playwright/index.mjs`：Chrome fixture IPC 测试已完成文件/目录操作、页面重载后恢复、多文件选择第二项、历史记录缺失、读取失败、文件不存在、原链接完整回填且没有自动解析/下载、原取消/重试状态边界、删除确认/返回、删除后重载仍不出现、删除失败保留任务和错误。共 10 场景，检查无 pageerror，文件操作只提交 taskId/outputIndex，不提交路径；任务删除不调用历史删除。
- 浏览器验证不调用真实系统打开命令、不访问站点、不读取 Cookie 或写入用户下载文件；原生文件关联打开仍需用户在应用中确认。
- 既有构建主包大于 500 kB 的 Vite 提示仍保留，不属于本次修复。
