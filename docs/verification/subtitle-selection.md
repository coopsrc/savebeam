# 字幕语言下拉多选

日期：2026-10-23（Asia/Shanghai）。

## 上游能力与本次范围

核对 [yt-dlp 官方字幕选项](https://github.com/yt-dlp/yt-dlp#subtitle-options)：`--list-subs` 可列出字幕；`--write-subs` / `--write-auto-subs` 选择人工/自动来源；`--sub-langs` 支持逗号分隔的多语言及正则；`--sub-format` 可指定格式偏好。官方 `YoutubeDL.process_subtitles` 在同一语言已有人工字幕时不会被自动字幕覆盖。

Savebeam 使用现有 JSON 字幕元数据，不额外运行 `--list-subs`；本次改为可搜索的多选下拉框，不扩展正则、自由创建语言、全部字幕、字幕转码或嵌入功能。

## 行为

- 单视频列出实际解析到的字幕语言，相同语言去重，标记人工、自动和格式（如 VTT/SRT）；不把 live_chat/danmaku 当普通字幕。
- 系列合并已读取详情中的语言与常用偏好；全局/订阅提供可复用的常用语言，未承诺每项都提供。已选却未提供的语言保留、明确提示跳过，不静默改任务配置。
- 最多 10 种；输入框点击展开列表，搜索只筛选已有选项，选中项是自动换行的标签，具备可访问名称的“×”按钮可逐个移除，一键清空。选满后未选项禁用，已选项仍可取消。清空关闭自动字幕；选择仅自动来源的语言会开启自动字幕，用户也可显式关闭。没有人工/自动字幕时显示空状态，不创建搜索文字。
- 单次弹窗草稿、取消/Escape、恢复全局默认、设置保存以及排队/恢复/重试快照保持原有规则。无新增持久化字段；系列元数据只增加安全投影的语言/来源/名称/格式，不包含字幕 URL 或请求头，最多 512 项。
- 后端把标签中的点转义再交给 yt-dlp，避免用户勾选字面语言却触发正则扩展匹配；保留已有标签字符/数量边界。
